
# DoorDash-Inspired Real-Time Streaming Pipeline

## Objective
Build an end-to-end food delivery event processing
pipeline using Apache Kafka and Databricks.

## Technology Stack
- Confluent Cloud Kafka
- Databricks Free Edition
- PySpark Structured Streaming
- Delta Lake
- Python
- GitHub Actions
- PyCharm

## Architecture
Delivery Events
    ↓
Confluent Cloud Kafka
    ↓
Databricks Structured Streaming
    ↓
Bronze → Silver → Gold
    ↓
Restaurant Analytics

## Project Status
Phase 1: Project setup in progress.
